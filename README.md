# OpenAgent

以工作流为主体的节点化 Agent demo。工作流组织任务、数据依赖和结果交付，Agent 是其中可配置、可替换的能力节点，聊天只是工作流的一种消费界面。

第一版用于本机开发与演示，不是生产部署版本。

当前产品开发仅在本仓进行：`main` 为限定验收通过的稳定线，`develop` 为唯一串行开发线。2026-10-09 已整理酒馆 P5、工作流初始化、源码 BAT、本机存档恢复及测试修补，验收与提交身份见 [工作区梳理与验收](docs/WORKTREE-ACCEPTANCE-2026-10-09.md)，分支规则见 [开发说明](docs/DEVELOPMENT.md)。本次仅本机收口，不推送、不部署，不开始 Gemini 实现。

版本元数据仍为 `0.2.0`；`v0.2.0` 标签固定的是 2026-10-07 的架构收口，不是当前分支 HEAD。按 [1.0 规划](docs/PLAN-1.0.md)，阶段 A/B/C 已按当期范围完成，当时本机同源常驻切换和限定真实供应商证据见 [0.2.0 架构收口基线](docs/BASELINE-0.2.0-2026-10-07.md)，不是 1.0 正式版。2026-10-07 用户另行授权提前推进的 [内核上下文精简](docs/PLAN-CONTEXT-COMPACTION.md)三批也已完成并提交，覆盖有序精简后追加、普通图接纳、一次性提示词和配置展示，以及集中定向测试、类型 / 构建和隔离浏览器验收。真实缓存 / 费用、规模测量和其他可选扩展继续后置。以下阶段性统计均按各自历史记录解释，不作为当前 HEAD 的全量验收结论。

## 当前 Demo

- Vue 工作台：创建、编辑和保存普通串行图，配置供应商与独立提示词当前资源、模型源及提示词引用节点。
- 普通 A -> B 示例：A 分析输入，B 使用 A 的本轮材料回答；两者分别维护上下文。
- 新精简示例：明确模型容量和独立策略，内核精简长期文本后由更新节点按序写回；仅一次提示词保留消费账本。
- Python Runtime：冻结运行依据，执行节点，接纳结果与对象写入，记录运行事实。
- 独立聊天消费者：提交输入、读取显式公开的展示结果；支持完成回合检查点和历史分支。
- 失败处理：区分暂停继续、成功结果接纳重试、确定失败节点重新调用和结果未知核实。

显式创建串行示例生成 18 个普通节点，不自动保存、运行或调用模型。首次使用需配置后端凭据引用、供应商资源及模型名称。没有 Agent 的普通处理图也可以运行，Agent 并非所有图的必需组成。

首次可读且没有本机存档的工作区建立空普通图。无关联旧内容的当前 Graph 定义、独立资源、精确包选择和未确认请求保护继续保留；缺包提供带诊断的只读历史，不回退旧执行。匿名聊天首页不初始化业务客户端，普通图从已保存定义打开精确 GraphChat 入口。

根据最新授权，旧固定流程、compat 图、旧会话及专用测试内容一起退出；引用旧历史的当前对象、manifest、共享旧 revision 及相关工作流/会话、事实和回执也按关联闭包整组删除，正常关联不再触发回滚保全，不另建兼容层或旧只读入口。旧宿主/私有执行器、旧 HTTP/静态客户端、固定工作台和兼容注册工厂已从源码移除，SQLite v14 在升级事务中执行上述清理，浏览器移除明确旧行。无关联当前数据及独立资源/配置保留，当前 pending 原请求保护不变、不自动重发；共用 Runtime、能力包和可信扩展保留。

第一批实际移除已通过受影响定向验证，208 文件 AST 本地导入扫描 0 缺失。第二批独立 wheel 安装最终 33/33 通过，限定 Mock 浏览器场景的只读联合核对 74/74 通过；前端状态同步窄修后 1 文件 13 项及类型/构建通过。具体版本、初轮失败、复测及未覆盖范围见 [实际移除记录](docs/REPLACE-REMOVAL.md)，重叠结果不累计。

## 已有证据与边界

发布前的定向验证覆盖模型资源编辑、普通串行图、确定失败续跑、完成检查点和历史读取。六回合中英混杂文本的 A 翻译、B 审核流程已有十二次实际 HTTP 200 响应，以及业务结果、只读重开和正文核验通过的记录；原验收包装进程因 Windows 日志原子替换 `WinError 5` 退出 1，该包装错误仍未修正。业务通过不等于整个验收包装通过。

六回合真实调用是原开发版本的证据，不是移除后目标代码的全量通过结论。本轮限定真实调用和本机常驻有各自证据，不代表浏览器触发常驻模型的收费端到端或全面使用验收。没有宣称 1M token 极限测试、无限长对话、任意失败可重试、并行 Agent Team、生产级插件市场或活动内核跨进程恢复已完成。完成回合的持久化读取与活动执行现场恢复是两回事。

服务仅面向本机 loopback，已移除旧 `--mode` 参数。配置真实模型的普通节点仍可能联网并产生费用。
