# OpenAgent

OpenAgent 是面向本机开发与验收的工作流式 Agent 工作台。工作流连接输入、提示词、模型、上下文、工具与结果交付；聊天是工作流的消费界面之一，不是唯一入口。

前端使用 Vue 3、TypeScript、Pinia 和 Vue Flow；后端使用 Python Runtime 与 SQLite。应用元数据为 `0.2.0`，不是 1.0 正式版或公网生产部署方案。

## 当前产品范围

- 当前以普通工作流和显式节点为主。旧 GraphChat/Tavern 创建入口、预设和独立聊天页面已退役；Lorebook 能力仍保留，`workflow.tavern` 包名不代表旧聊天入口仍可用。
- 工作流引用全局命名模型配置。凭据只通过供应商设置保存到受保护的私有存储，不写入工作流或通用资源；宿主不支持保护时应拒绝保存。
- 当前数据、变量和会话操作以源码与[使用手册](docs/USER-GUIDE.md)为准。65–68号描述后续阶段，不是已安装实现；本轮文档整理不提前应用其目标。
- 显式运行真实模型节点可能联网并产生费用。历史限定验收不代表所有模型、工作流或部署场景均已验收。

## 分支与启动安全

- 日常开发使用 `develop`，由 `start-dev.bat` 选择当前开发工作区。
- `start.bat` 仍要求唯一、干净且匹配本地 `main` 的工作区；不回退到 `develop`。截至 2026-10-17 本轮核对，当前工作区为 `develop`，未建立 `.local/stable-main`。不要为满足旧文档而创建该工作区或绕过检查。
- 启动器使用可见控制台，不自动安装依赖、不拉取代码、不接管已有端口。启动、安装和停止命令见[快速启动](docs/QUICKSTART.md)；文档中的操作命令不构成本轮执行授权。
- 旧回执不能证明当前服务、数据库或远端状态。代码更新不会自动迁移数据库或重启已有服务。

## 数据与安全边界

- 正常初始化不代表清理或迁移旧数据。任何显式清理或迁移都须先核对准确目标和授权范围；不要从历史交接回执推断当前数据库状态。
- Key、原始请求及回执属于受保护数据，不应写入文档、日志或代码变更。未知请求只核实同一原请求的回执，不自动重发或更换凭据重试。
- 保留原始授权、验收事实、来源信息与哈希；历史记录中的“当前”“下一步”“已停止”等只表示其登记时点。
