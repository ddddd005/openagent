# OpenAgent

以工作流为主体的节点化 Agent demo。工作流组织任务、数据依赖和结果交付，Agent 是其中可配置、可替换的能力节点，聊天只是工作流的一种消费界面。

第一版用于本机开发与演示，不是生产部署版本。

下一阶段按 [1.0 规划](docs/PLAN-1.0.md)先整理代码、退出旧架构并完成基础使用验收，再进入 1.0；长上下文维护、规模测量和可选能力扩展后置。当前仍是 Demo，不代表 1.0 已完成。

## 当前 Demo

- Vue 工作台：创建、编辑和保存普通串行图，配置供应商与独立提示词当前资源、模型源及提示词引用节点。
- 普通 A -> B 示例：A 分析输入，B 使用 A 的本轮材料回答；两者分别维护上下文。
- Python Runtime：冻结运行依据，执行节点，接纳结果与对象写入，记录运行事实。
- 独立聊天消费者：提交输入、读取显式公开的展示结果；支持完成回合检查点和历史分支。
- 失败处理：区分暂停继续、成功结果接纳重试、确定失败节点重新调用和结果未知核实。

显式创建串行示例生成 18 个普通节点，不自动保存、运行或调用模型。首次使用需配置后端凭据引用、供应商资源及模型名称。没有 Agent 的普通处理图也可以运行，Agent 并非所有图的必需组成。

可读取且尚无本机存档的首次工作区默认建立一个空普通图；新后端库默认不启用兼容包。已有工作区、原包选择及未确认请求保留，不自动迁移或清空；缺已保存包时提供带诊断的历史只读，不回退旧执行。具体范围见 [默认入口与初始化收口](docs/REPLACE-DEFAULTS.md)。

聊天首页无身份时不初始化业务客户端；普通图从已保存定义打开精确图入口，旧会话暂时保留显式隔离交接，不作为匿名 fallback。工作台未绑定旧会话时不生成匿名链接，见 [聊天入口分派收口](docs/REPLACE-CHAT-ENTRY.md)；旧宿主和正式兼容客户端尚未退役。

## 已有证据与边界

发布前的定向验证覆盖模型资源编辑、普通串行图、确定失败续跑、完成检查点和历史读取。六回合中英混杂文本的 A 翻译、B 审核流程已有十二次实际 HTTP 200 响应，以及业务结果、只读重开和正文核验通过的记录；原验收包装进程因 Windows 日志原子替换 `WinError 5` 退出 1，该包装错误仍未修正。业务通过不等于整个验收包装通过。

这些是原开发版本的证据，不是本发布目录重新取得的全量通过结论。本工作区后续取得的普通图供应商配置浏览器证据见切片记录，不代表完整浏览器联合验收。没有宣称常驻部署、1M token 极限测试、无限长对话、任意失败可重试、并行 Agent Team、生产级插件市场或活动内核跨进程恢复已完成。完成回合的持久化读取与活动执行现场恢复是两回事。

服务仅面向本机 loopback。`offline` 是旧宿主模式标签，不是新版工作流的网络禁用开关；配置真实模型的普通节点仍可能联网并产生费用。
