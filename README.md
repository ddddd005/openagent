# OpenAgent

以工作流为主体的本机节点化 Agent 工作台。工作流组织输入、提示词、模型、上下文、工具与结果交付；Agent 是其中可配置的执行节点，聊天是工作流的消费界面，不是唯一入口。

前端使用 Vue 3、TypeScript、Pinia 和 Vue Flow，后端为 Python Runtime + SQLite。项目当前用于本机开发与验收，版本元数据为 `0.2.0`，不是 1.0 正式版或公网生产部署方案。

## 当前能力

- 普通工作流：画布编辑、端口连线、控制顺序、会话对象绑定、保存定义及运行历史。
- 现行节点目录：44 个可执行声明、41 个节点家族、9 个分类的二级菜单；同类型仅保留当前路线，不提供历史版本菜单。
- 模型协议：DeepSeek Chat Completions 与 Gemini generateContent；模型来源、普通模型调用及 Agent 按协议配置。
- Agent：原生上下文、工具执行与 `final_answer` 交付、多轮历史、同进程暂停继续，以及保留成功结果后的接纳重试；当前原生 Agent 不开放失败节点重试策略。
- Gemini 思考：按已登记型号选择 Token 预算或强度，摘要独立展示；供应商签名按原始 part 顺序保存并回传，不作为回答正文。
- 提示词与上下文：图内材料、全局提示词组、每次装配/仅一次生命周期，以及可选内核上下文精简策略。
- 消费界面：通用 GraphChat、独立酒馆聊天壳、全局世界书；工作台支持完成回合的候选状态操作，酒馆只接已完成回合分叉。
- 请求保护：结果未知时核实原 body/key，不自动重发请求或重放工具；无法安全读取的浏览器存档保留原文并提供导出与独立工作区。

普通串行示例与精简示例使用同一现行上下文路线，只在是否连接精简策略上不同。创建示例、配置与保存不会自动调用模型；显式运行真实模型节点可能联网并产生费用。

## 启动

先按 [快速启动](docs/QUICKSTART.md) 安装 Python/Node 依赖，再使用仓库根目录的 Windows 入口：

| 入口 | 源码分支 | 工作台 / 后端 | 默认数据库 |
| --- | --- | --- | --- |
| `start.bat` | 干净的本地 `main` 工作区 | `5178` / `8765` | 入口工作区 `.local/dev/workflow.sqlite` |
| `start-dev.bat` | 当前工作区 `develop` | `5179` / `8766` | 入口工作区 `.local/develop/workflow.sqlite` |

两个入口均使用可见控制台，不隐藏后台启动，不拉取代码、不安装依赖，也不接管端口上的旧服务。可以先运行 `.\start.bat -CheckOnly -NoBrowser` 核对启动条件；停止时使用该次启动打印的完整停止命令。

模型密钥只注入后端进程环境，供应商表单保存 `env:DEEPSEEK_API_KEY` 或 `env:GEMINI_API_KEY` 引用，不保存密钥正文。配置、运行和恢复操作见 [使用手册](docs/USER-GUIDE.md)。

## 主干与更新

2026-10-09，现行测试版按用户授权晋升为 `main`，并已正常推送；晋升提交 `0c158e7` 是本轮文档订正前的主干基线。`main` 是产品主干，`develop` 是唯一串行开发与隔离验收分支，不维护两套产品实现。

旧正式版仅归档供参考。正常推送替换远端 `main` 的当前源码，不抹掉 Git 提交历史，也不会自动更新正在运行的服务、数据库、虚拟环境或前端产物。旧主干归档标签 `main-before-node-unification-2026-10-09` 目前只在原开发机本地，未推送；本机 `.local/` 中的 ZIP、数据库快照、依赖、日志和验收截图也不随克隆分发。归档边界见 [主干晋升记录](docs/MAIN-PROMOTION-2026-10-09.md)。

`v0.2.0` 标签固定的是 2026-10-07 的架构收口快照，不等于当前 `main`。重新部署必须核对目标提交、停止已知旧服务，并从同一份源码安装/构建后显式启动。

## 数据与限制

当前只有 Graph 架构。SQLite 存储 v15 按明确退役的节点 ID/版本、包锁及旧提示词资源识别旧测试图，删除旧图和关联记录；浏览器同步移除明确旧路线的整图条目，不静默改成新版本。无关联现行数据、现行供应商和 schema 2 提示词资源保留；未知插件/版本不会仅因目录缺失被猜测删除。升级前应另行备份自己的数据。

完成历史的持久化重读不等于活动 Agent 内核的跨进程恢复。当前不保证无限长对话、1M token 极限、任意失败可重试、并行 Agent Team 或完整移动端适配。Gemini 型号按代码能力表明确登记，未知型号拒绝，不根据名称猜测；DeepSeek 路线目前只接受关闭思考，模型响应不流式输出。

最近已有前端 928 项、主干定向后端 239 项及构建通过记录。此前后端全量为 3008 项通过、50 项已知基线失败、9 项跳过，并非全绿；不同批次的定向数不累加，也不代表真实供应商全面在线验收。范围见 [现行节点与验收](docs/NODE-DIRECTORY-2026-10-09.md) 和 [晋升记录](docs/MAIN-PROMOTION-2026-10-09.md)。
