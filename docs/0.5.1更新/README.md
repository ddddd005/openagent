## 本期已确认方向

1. 一次 Agent 调用具有自己的工作区，加载工具能力，支持连续调用同一个有运行中数据的地图进程。
2. 模型给出有效 `final_answer` 后结束模型循环，程序继续完成工作区收尾和节点结果组装。
3. 工具负责通过数据层读取、提交和保存自己的数据，工作区负责按顺序通知收尾及释放资源。
4. 模型提供的内容与工作区导出内容合并到现有 `result`，本期不增加对外输出端口。
5. 模型报错或用户终止时停止，不执行正常结束保存；已经提交的数据按实际事实保留。
6. 地图状态与 Agent 上下文不要求同一次提交。检查点仍须实际覆盖相关工具数据，才能支持回到历史回合。

## 2026-10-23 P0 确认结果（Q1-Q6）

1. 合成格式：无导出时只用模型 final 文本；有导出时为「模型 final 文本 + 空行 + 导出文本」，TEXT@2 不变。
2. 收尾拆分：`finish`（通知正常结束，工具保存+导出）与 `close`（释放/停止）分开，程序在两者之间合成。
3. 实例数量：每 Agent 至多一个工作区绑定/实例；多工具共享该实例，多绑定明确拒绝。
4. 事实与上下文：不改执行事实/回执，原始 final 保留；合成只落 result 输出，不进入下一轮上下文。
5. 数据与检查点：本轮只做 P1/P2 机制+受控样例，不新增通用数据写端口；P3/P4 待真实地图工具完成后另立契约。
6. 收尾失败：不自动也不人工重试；finish/close 失败即节点失败，报告阶段与已知提交事实。
