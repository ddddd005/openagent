```powershell
$repo    = 'D:\agent rp\方案1\openagent'
$source  = 'G:\AI\shapan\sandbox_demo'
$stage   = Join-Path $repo '.local\sandbox-tool-adaptation'
$copy    = Join-Path $stage 'source\sandbox_demo'
$evidence= Join-Path $stage 'evidence\manifests'

# 1) 绝对路径与边界核对：目标必须在 <repo>\.local\ 内，且当前不存在
$repoResolved   = (Resolve-Path -LiteralPath $repo).Path
$sourceResolved = (Resolve-Path -LiteralPath $source).Path
if (-not $sourceResolved.StartsWith('G:\AI\shapan\', 'OrdinalIgnoreCase')) { throw 'unexpected source root' }
if (Test-Path -LiteralPath $stage)  { throw "stage exists, inspect before use: $stage" }
$stageFull = [IO.Path]::GetFullPath($stage)
if (-not $stageFull.StartsWith((Join-Path $repoResolved '.local') + '\', 'OrdinalIgnoreCase')) { throw 'stage outside .local' }
New-Item -ItemType Directory -Force -Path $evidence | Out-Null

# 2) 复制完整代码/说明/测试/world；排除缓存、运行库、日志（来源当前无 sqlite，仍显式排除）
robocopy $sourceResolved $copy /E /XD __pycache__ .git /XF *.pyc *.sqlite3 *.sqlite3-* *.log /NFL /NDL /NP
if ($LASTEXITCODE -ge 8) { throw "robocopy failed: $LASTEXITCODE" }

# 3) 清单函数：相对路径<TAB>字节数<TAB>SHA-256（显式 UTF-8 写证据）
function Write-Manifest([string]$root, [string]$out) {
  $rootFull = [IO.Path]::GetFullPath($root)
  Get-ChildItem -LiteralPath $rootFull -Recurse -File |
    Where-Object { $_.FullName -notmatch '\\__pycache__\\' -and $_.Extension -ne '.pyc' } |
    Sort-Object FullName | ForEach-Object {
      $rel = [IO.Path]::GetRelativePath($rootFull, $_.FullName)
      "{0}`t{1}`t{2}" -f $rel, $_.Length, (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash
    } | Set-Content -LiteralPath $out -Encoding UTF8
}
Write-Manifest $sourceResolved (Join-Path $evidence 'source-before.tsv')   # 来源基线（只读）
Write-Manifest $copy           (Join-Path $evidence 'copy-after.tsv')      # 副本
# 4) 用 Compare-Object 比对（应无差异）；差异行写入 evidence 并停下报告
Compare-Object (Get-Content (Join-Path $evidence 'source-before.tsv')) `
               (Get-Content (Join-Path $evidence 'copy-after.tsv')) |
  Set-Content (Join-Path $evidence 'copy-diff.txt') -Encoding UTF8
# 5) 复核来源未被改动、暂存树不入 Git（输出进证据）
git -C $repo status --short | Set-Content (Join-Path $evidence 'git-status.txt') -Encoding UTF8
git -C $repo check-ignore -v '.local/sandbox-tool-adaptation' |
  Set-Content (Join-Path $evidence 'git-ignore.txt') -Encoding UTF8
# 6) 后续改造包单独清单（applied-package.tsv），与 copy-after.tsv 分开，避免把改造混作来源未改
```

### 3.3 `test_sandbox_worker_protocol.py`（A6 进程级 + A2 进程共享 + A9 导出协议）

- 阶段：S2（worker 落地后）。
- 被测对象：包内 `worker.py` 子进程，不经 Host。协议建议（S0-C 候选，最终以 S0-A/S2 契约为准）：stdin/stdout 各一行一个 JSON 对象；`{"op":"query","request":{...}}`、`{"op":"execute","request":{...}}`、`{"op":"snapshot"}`、`{"op":"finish"}`、`{"op":"close"}`；stderr 只放诊断；stdout 不得出现非协议文本。
- 启动方式（模拟包适配器）：`[sys.executable, "-X", "utf8", "-B", "-m", "<pkg>.worker", "--runtime-dir", <runtime>]` + `cwd=<pkg-dir>` + `PYTHONPATH=<pkg-dir>` + `PYTHONUTF8=1`；`text=True, encoding="utf-8"`；每次读一行断言是 JSON dict（参考 `test_v3.py:323-331` 的显式 UTF-8 做法）。
- 用例与断言：
  1. 初始化：进程启动后首个 `snapshot` 返回初始 world state（revision=0、clock=2024-01-01T08:00:00、scene=None，`sandbox_v3.py:45`）；`world` 资源 JSON 字节不变。
  2. 同实例业务链路（A2 进程级）：`get_character` → `pre_move` → `move` → `get_character` 连续执行；断言同一 pid、位置已变、事件 id 递增、后一次看见前一次修改。
  3. `finish`：（i）有正式事件时返回 `{"ok":true,"text":...}` 且文本只含本次事件；（ii）零正式事件时返回 `{"ok":true,"text":null/None}` 或约定空导出（宿主 `finish` 只接受 `{"text":str}` 或 `null`，见 `graph_tool_host.py:116-127`，零事件应返回 `None`，最终 result 只用模型文本）；（iii）快照文件原子落盘（先写临时文件再 `os.replace`，实现时断言无半写）。
  4. `close`：发送后进程在超时内退出且 returncode==0；重复 close 报错；退出后端口关闭、无残留进程。
  5. `abort`：发送终止后进程退出、快照文件内容与 mtime 不变、不产生导出。
  6. 超时：用 `tests/fixtures/fake_worker_hang.py`（只读 stdin 不返回）替换 worker 路径，断言客户端在超时后抛明确错误并 kill 子进程，不重发命令。
  7. 无效返回：`fake_worker_invalid.py` 返回非 JSON/非对象/多行文本，断言客户端报“invalid response”类错误且不把内容当结果。
  8. 进程崩溃：`fake_worker_crash.py` 读到命令后 `os._exit(1)`，断言调用报错、进程被回收、后续调用显式失败。
  9. 退出码非零：`fake_worker_bad_exit.py` 收 `close` 后 `sys.exit(3)`，断言 close 报错且不宣称已关闭。
- 失败注入点：伪 worker 脚本（`tests/fixtures/`，不改产品代码）或对“worker 路径/客户端请求函数”的测试缝：建议 S2 在适配器模块内保留模块级 `WORKER_PATH`/`_request` 可替换常量（仅测试用），否则测试只能通过伪包包装达到注入；该缝需在 S2 实现时明确记录，不得为测试在生产路径加分支。
- 清理断言：每个用例 `try/finally` 关闭/杀死子进程；测试结束用 `psutil` 不可用（无第三方依赖）时，以 `Get-CimInstance Win32_Process` 过滤包路径记录证据（§4.2）。

## 6. 风险与未决项

1. **数据接口缺口（A7/A8/A11 的硬前置）**：当前 `WorkspaceToolBindingAdapter.finish(handle, invocation) -> {"text": str} | None`（`tool_binding_contract.py:78-127`）没有对象/数据层写入口；`GraphToolHost` 的 workspace-finish 只把返回值投影为导出文本（`graph_tool_host.py:249-273`）；执行器只做文本合成（`agent_executor.py:288-319`）；`agents.execute@10` 无对象能力（03 勘察 §1.3）。因此“工具自行经数据层保存”必须在 S0 由用户确认有限接口（S0-B 05 文档处理）；未确认前 A7/A8 只能算隔离存储，A11 不能做产品链路。本文测试设计已按两条轨道固定（隔离替身 vs 正式接口）。
2. **真实时间/票据**：TTL 5 分钟 + `recorded_at` 墙钟；长会话、暂停、恢复、检查点回放都可能跨分钟。若不引入注入时钟，A8 快照等价、A9 导出、A11 两回合比较会出现不稳定；S2 必须落地时钟注入（§4.4）。
3. **进程退出竞态/残留**：close 需“发送退出→限时等待 returncode==0→超时 kill 并报错”（样例语义：`examples/.../package.py:165-181`；失败阶段 `workspace_close_failed`）。测试要断言无残留进程（`Get-CimInstance Win32_Process` 过滤包/worker 路径）并在 `finally` 清理；Windows 下子进程串行管道可能受杀进程时机影响，超时值显式（建议 10-30s）且失败报原始 returncode。
4. **Windows 编码**：世界 JSON/提示文本是 UTF-8 中文；本次只读核对已复现“PowerShell 默认解码读取 UTF-8 JSON 出现乱码”，因此 worker 协议、证据脚本、测试读取必须显式 UTF-8（`-X utf8`、`PYTHONUTF8=1`、`encoding="utf-8"`、`Set-Content -Encoding UTF8`）。stdout 只放 JSON 行，诊断走 stderr；禁止把中文文本交给默认 ANSI 控制台。
5. **快照大小**：单会话对象默认上限 1MB（`host_sdk.py:22,300`），类型可配至 4MB（`:356`），preload 数 ≤1024（`session_preloads.py:16`），单节点写集 ≤256（`session_objects.py:479`）。完整世界含事件日志会持续增长（每次操作一条事件；101 条事件测试会明显放大 JSON）；A8/A11 必须测量快照字节数并断言小于所选类型上限，否则要拆对象/压缩（结构由 S0-B 定）。
6. **检查点旧会话兼容**：新增 `session_preloads` 会产生新的固定定义修订，旧检查点缺 `preloaded_items` 时 fork 会拒绝（`checkpoint_loading.py:219-228`、`workflow_chat_service.py:302-317`；03 勘察 §2.2/§2.3）。A11 只用“声明之后创建的新会话”；不得宣称旧聊天历史可恢复。
7. **清理与交付边界**：`.local` 成果不入 Git（`.gitignore:12`）；S5 只交付隔离验证+证据+回执，不自动安装到服务目录、不改启用选择、不迁移原世界存档（03 规划 §3.2:88-91）。清理 `runtime/`/进程/临时 DB 前必须核对解析后的绝对路径，仅限 `<repo>\.local\sandbox-tool-adaptation\` 与 `pytest-sandbox-*`；`source/` 与 `evidence/` 保留。
8. **并发语义变化**：资源/运行分离后“两个实例共享同一可写世界目录”的旧并发规则不再成立（`test_v3.py:290-306`）；A3 改造后必须把语义变化写进用例名/回执，防止把旧 CAS 结论误当新实现结论。
9. **未决契约**：包身份/目录名、worker 协议字段、快照结构、数据接口与检查点类型由 S0-A/S0-B/用户确认；本文用占位常量与候选字段，未确认前不写实现、不宣称注册成功。
