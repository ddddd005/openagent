## 3. 决定落实与真实链

1. `session_preloads` 严格为 `{object_key,value}` 数组；类型、版本、scope、owner、readers/writers 由同文档 `object_bindings` 唯一维护。禁止同键再声明 binding default 或 registrar。旧注册节点继续原行为，不迁移或伪造隐藏节点。
2. 新会话返回时列表项已建立，revision 为 1；创建请求回放不再次初始化。两个会话独立；初始化、跨对象引用或 seed 失败由原事务回滚。完整对象引用校验在初始集合齐全后执行，未跳过旧基础对象规则。
3. 固定预加载变更沿原确认派生。独立磁盘包链实际验证初值 2 → 原会话运行至 8；修改初值 100 需确认派生，新会话为 100，旧两会话仍 8/2。配置复制保留列表但无会话。
4. 真实 `LocalWorkflowPackageSource` 从隔离磁盘目录加载无默认值结构类型和消费者节点，核对目录的准确类型与来源；节点经原对象 API 读写，产生 full/diff，历史 root 分叉恢复 5，关后重开读回并继续执行。不是只注入内存 registry 的替代证据。
5. 聊天真实链验证第一轮初始态、reroll、候选选择及 floor fork；通用结构和变量均恢复所选历史值，原会话不变。缺键、额外键、类型或 CAS 错误拒绝且回滚。
6. 真实原生 Agent 图移除旧变量注册节点，使用预加载值 4，经受控离线模型调用原 `read/set/add` 工具至 12，检查点及分叉仍为 12。去掉 writer ACL 时准备阶段即拒绝，transport 零调用、值仍 4。工具集没有新增 register/create/declare 权限。
7. 前端真实已保存配置路径为组件 → Store edit → `acceptDraft` → `submitConfigurationDocument` → 既有证据/确认/回执接纳，不要求再调用已退役的 `saveWorkflow`。客户端事件覆盖入口点击、变量/JSON/未赋值、增删、私有 ACL、切换重置与陈旧提交；Store 覆盖一次原子提交及运行/归档/fixed/unknown 门禁。

## 4. 交叉发现与处置

| 发现 | 修后行为与证据 |
| --- | --- |
| 保存可接受专用 type ID 的其他版本，但普通历史分区拒绝 | 统一保留 variable/chat/effective-context 的专用 ID；仅准确 `workflow.variable@1` 进入变量预加载，其余保存时明确拒绝 |
| 可选历史分区移除后物化残留空分区 | 同链已有 `preloaded_items` 后移除字段明确失败；清空保留 `{}`。旧链从未含字段时仍保持旧形状；新增形状回归 |
| schema 非本地引用会触发默认 resolver | 预加载准入在类型值校验前拒绝远程/file/相对引用。纯离线探针拦截到旧实现的尝试，没有真实网络 |
| 本地 fragment 可指到 default/const 中的间接外部引用 | 用不提供外部检索器的既有 `referencing.Registry` 跟随实际本地目标并去重；不误扫未引用的普通数据。合法递归结构、嵌套作用域与锚点正测；坏目标、纯无产出循环及未解析引用返回明确诊断。新增 18 项回归，拦截断言零外部调用 |
| 前端按 ID/version 找到排在前面的同名 content 类型 | 查找加 `scope=session`；新增独立 Store 回归，独立源码探针修后两种目录顺序一致通过 |
| 部分自动改键不能覆盖包内 opaque 引用 | 已创建对象键作为稳定身份，UI readonly、Store 拒绝改键；变量名称、初值和 ACL 仍可修改，不给通用核心加入包专属配置重写 |
| 同 tick 切工作流后旧表单可能仍可提交 | 使用既有同步 volatile basis reset，旧 handler 检查 editing，回归确认不会写入新目标 |

schema 防外部引用是预加载消费边界，不声称可信包导入代码已被沙箱隔离。不存在新的自动补值、恢复或重放机制。
