```sql
-- (a) native 行计数
SELECT COUNT(*) AS native_definition_save
FROM idempotency WHERE operation = 'graph.definition.save';

-- (b) origin 行计数
SELECT COUNT(*) AS origin_definition_save
FROM idempotency
WHERE operation = 'graph.application.command-identity.v1'
  AND json_valid(result_payload)
  AND json_extract(result_payload, '$[0].application_identity.operation') = 'definition.save'
  AND json_extract(result_payload, '$[0].application_identity.native_receipt.table') = 'idempotency'
  AND json_extract(result_payload, '$[0].application_identity.native_receipt.operation') = 'graph.definition.save';

-- (b') 无 JSON1 时兜底（紧凑 JSON）
SELECT COUNT(*) FROM idempotency
WHERE operation = 'graph.application.command-identity.v1'
  AND result_payload LIKE '%"operation":"definition.save"%';

-- (c1) native 总数 / origin 总数 / 可配对 native 数 / native 缺 request_digest 数
WITH nat AS (SELECT * FROM idempotency WHERE operation = 'graph.definition.save'),
     org AS (SELECT * FROM idempotency
             WHERE operation = 'graph.application.command-identity.v1'
               AND json_valid(result_payload)
               AND json_extract(result_payload, '$[0].application_identity.operation') = 'definition.save')
SELECT (SELECT COUNT(*) FROM nat) AS native_rows,
       (SELECT COUNT(*) FROM org) AS origin_rows,
       (SELECT COUNT(*) FROM nat n WHERE EXISTS (
          SELECT 1 FROM org o
          WHERE json_extract(o.result_payload, '$[0].application_identity.native_receipt.key') = n.key
            AND json_extract(o.result_payload, '$[0].application_identity.native_receipt.operation') = 'graph.definition.save'
       )) AS native_with_origin,
       (SELECT COUNT(*) FROM nat WHERE request_digest IS NULL) AS native_missing_request_digest;
```

**结果解释（冻结口径，避免“有行=仍需要”）**：

| 观察 | 对“退役读取支持”的含义 |
| --- | --- |

## 6. Q19：平台级资源专用路由与 application `resource.*` 双入口

### 6.1 结论摘要

1. **同源**：专用 `/api/graph/resources/{read,list,save,delete}` 经 `graph_http.dispatch_platform` 的 `global_routes` 映射到与 application 信封相同的 operation；两者都进入同一 `GraphApplication.command/query`、同一 `validate_parameters`、同一业务服务与 `GlobalResourceStore`（[graph_http.py:31-48](../../backend/src/phase1_agent/graph_http.py#L31-L48)、`:66-83`；[graph_application.py:66-90](../../backend/src/phase1_agent/graph_application.py#L66-L90)）【静态事实】。
2. **服务选择同源**：`server.management_request` 对专用四路径显式返回 True（`server.py:129-134`），对 `commands` 的 `resource.*` 前缀返回 True（`:161`），对 `queries` 恒 True（`:158-159`）；两条入口都选 `get_management_service()`（`:525-529`），不构造执行权威【静态事实】。
3. **仓内生产调用者只有 application 入口**：工作台 Vue 全部资源读写走 `/api/graph/queries`、`/api/graph/commands`、`/api/graph/receipts/read`；适配器里的字符串 `/api/graph/resources/save` 只是持久化旧坐标，不是 HTTP 目标（[workflowApplicationApi.ts:13-31,55-85](../../frontend/src/adapters/workflowApplicationApi.ts#L13-L85)）【静态事实】。
