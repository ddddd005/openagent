`packages.configure` 的直接管理实例调用边界仍需明确，这是 [130 号](130-项目级支撑P1范围与职责确认回执-2026-10-20.md) A6/D8/Q6 及其第 12 节已登记的问题，**不计为本轮新发现，不擅自宣布关闭**：

- 正常 `WorkflowHost` 路径按内部 authority 取得执行实例，见 [分派分类](../../backend/src/phase1_agent/graph_application_contracts.py#L205)、[应用分派](../../backend/src/phase1_agent/graph_application.py#L86)和 [Host](../../backend/src/phase1_agent/workflow_host.py#L185)。

- 工作流 `public_contracts.operation_groups.scope` 的业务分组与内部服务 authority 不是同一契约；仅因同为 management/execution 字样而分组不同，不能直接认定分派缺陷。后端路初报的“新增 P2”疑问经 Lead 回查 130 后已撤回，最终按既知风险登记。
- 建议正常包切换统一经 Host；直接管理实例的包切换不作为已验证使用方式。若需要正式支持该入口，应由用户先明确责任，再安排守卫/分派的窄修与验证。本篇不擅自改变其支持范围或代码行为。

## 5. 面向使用者的候选更新说明

以下以“当前候选树将纳入交付”为前提，不表示 main 或远端已更新：

1. **工作流管理更集中。** 工作流区域承载配置、会话、运行和请求核实；目录以摘要加载，打开时再取得详情。
2. **复制只带配置。** 从正式 current 配置创建新身份，允许归档来源；预加载配置一并复制，但副本没有源会话、运行记录、检查点或会话当前值。
3. **新增通用会话预加载数据。** 变量和获准普通结构可在配置中声明，创建会话时一次初始化；已有会话不持续追随，历史恢复不重新覆盖初值。
4. **可以手动加入可信节点/工具包。** 下载解压放到指定目录，重启取得来源快照，再按准确版本显式启用；不是放进去就自动启用，也没有市场或联网安装器。
5. **同类工具无需逐个改 Agent 内核。** 包显式提供加载节点、目标实现、参数和提示投影，工作流完成绑定；普通节点不会自动获得 Agent 工具身份或权限。
6. **错误按实际环节反馈。** 普通工具参数错误使当前整批不执行，由当前 Agent 订正；已完成的模型/工具不会因为后续接纳或通知问题默认重跑。
7. **结果不明时有统一核实入口。** 原请求可以发现、查看并只读核实；关闭警告不等于结案或解锁，系统不自动重发未知请求。
8. **正常配置编辑减少打扰。** 通知位于顶层浮层，蓝色信息、绿色成功、黄色警告、红色重大问题；普通编辑不逐次弹窗。完整颜色/消退时序未在本次浏览器简验中逐项覆盖。
