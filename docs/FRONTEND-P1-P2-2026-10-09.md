## 节点酒馆入口

新增精确版本的 `node-fields` 扩展及 `TavernPresentationFields.vue`。点击时固定工作流、节点、已保存修订和会话，先等待本机草稿确认，再在异步操作前后核对上下文。

入口核对保存定义内的节点、唯一公开的酒馆展示输出、输入及会话修订。未保存、节点不一致或会话不匹配会显示诊断，不隐式发布、重绑或运行。

无会话时由用户明确点击“新建会话并打开”。新增 saved-only 会话创建应用动作，只使用精确已保存修订；创建本身不运行模型。新窗口打开失败或上下文变化时保留诊断，失败窗口关闭。

URL 明确指定的会话不再被另一会话的旧 pending 覆盖。旧请求保留并单独提示、导入及核实，不自动执行。裸 `/tavern/` 保留未绑定诊断，不猜测会话，也不猜测不同端口的工作台地址。

## 本机草稿契约

SQLite `STORAGE_VERSION = 16` 新增独立 `local_editor_drafts` 表，不把编辑草稿混入运行事实。v15 到 v16 只增加草稿结构；旧退役清理限定为 `0 < old_version < 15`，不因本次升级再次清理 v15 数据。

经现有 GraphApplication 登记：

| 权限范围 | 命名查询 | 命名命令 | 草稿种类 |
| --- | --- | --- | --- |
| 管理 | `draft.read`、`draft.list` | `draft.save` | `workbench`、`form`、`intent` |
| 消费 | `consumer.draft.read`、`consumer.draft.list` | `consumer.draft.save` | `chat-client`、`chat-input` |

地址严格包含五个字段：

```ts
{
  scope: "management" | "consumer",
  kind: "workbench" | "form" | "intent" | "chat-client" | "chat-input",
  key: string,
  workflow_definition_id: string | null,
  workflow_session_id: string | null
}
```

UUID 非空时须通过身份校验。消费草稿必须指定工作流，聊天输入必须指定会话；会话须属于该工作流。消费端不能访问管理草稿，原请求按既有消费命令校验，不借存储权限扩大业务操作范围。

记录有独立格式版本、sequence 和时区时间戳。写入使用 expected sequence 的 CAS 与幂等请求身份，回执和记录在同一事务提交。`value: null` 是保留 sequence 的删除标记，不物理删除后重置代次。单条草稿按实际 JSON 字节限制为 3,900,000 bytes。

常见秘密字段禁止进入通用草稿。API Key 不因防丢失而保存到此仓库，本轮仍使用原环境凭据引用；该字段防护不是对任意自由文本的自动秘密识别或加密承诺。

## 编辑与请求保管

图、资源及表单按归属保存。覆盖节点标题、模型配置、提示词引用、世界书、通用 JSON/文本/数字、对象与事件绑定、事件 payload、运行输入和预算，以及酒馆/普通聊天输入。

未应用的表单和无效 JSON 保留原文。数字输入保留 `-`、`1e` 和 `02048` 等原始编辑文本；无效数字不能提交之前的有效数值。配置、schema 或生命周期依据改变时保留旧草稿并提示冲突，不默应用。成功的同工作流本地配置接受新依据，外部变更仍冲突，自动副本不改写旧工作流草稿。

普通编辑采用 200ms 最新值缓冲；业务操作与应用内切换前强制等待确认。切换节点、面板、工作流、会话，以及打开酒馆等路径遇到落盘失败会保持当前编辑上下文。迟到读取、写入或删除响应不能改变已切换的表单。

工作流、三类资源与聊天消费者在发送业务命令前确认原请求落盘，接纳后再确认本机接纳状态。结果未知只按原请求身份读取原回执，不生成新业务身份，不自动重发模型或工具。持久化失败不显示“已保存”。

CAS 冲突不覆盖另一页面的版本；工作台将本页编辑保存为独立冲突记录。表单依据冲突由用户明确载入或放弃。尚在内存而未确认落盘的内容不能承诺关闭后恢复，关闭警告不保证异步保存完成。

## 浏览器旧记录

新恢复以本机后端为权威。浏览器旧图、资源 pending 和聊天 pending 只在各自入口明确导入；原始字节不覆盖、不删除，未知或损坏格式不猜测修复。

工作台导入使用原文 SHA-256 的后端标记防止重复导入，身份冲突明确阻止，不替换既有本机图。导入原请求只保管并核实原回执，不执行旧业务。浏览器不再作为新业务草稿的唯一保存依据，收起等轻量偏好仍可留在浏览器。
