## P5：编辑与连线

- 节点正文与插件表单置前。UUID、配置 JSON、版本与对象访问契约收进“技术详情”；运行目标、前序节点及“允许聊天端读取的结果”收进“运行设置”。折叠不扩大公开读取权限。
- 全局提示词组和 `prompts.group@2` 共用成员编辑器，保留 ID、metadata、角色、位置、生命周期和精简许可。节点表单通过精确声明的前端扩展及现有 SDK/CAS 应用，不升级节点或数据 schema。
- 数字保管原始文本，`1e-` 可切换或重开恢复，不能用上一次合法数字冒充已应用。应用后同步主表单和数字草稿依据。
- 管理专属只读 `definition.inputs` 从后端节点声明读取输入。不完整图仍保留可编辑字段和诊断；`required_for_run` 只对应激活节点，编译失败为 `null`，不把所有声明当成本轮必填。消费端无此权限。
- “本次输入”优先呈现 TEXT 字段；复杂对象、PROMPT 和未声明输入保留高级 JSON 及原值。只应用输入，不发布或运行。
- 工具栏提供可见“添加节点”图标，分类菜单支持搜索，仍不提供历史版本选择。
- Handle 命中框为 24px，悬浮显示外环，拖线时区分兼容和不兼容；结束吸附半径为 28px。画布和 store 共用检查：动态端口、精确类型/schema、重复、单源基数、自环及数据/控制组合环。
- 失配旧线保留、标红并持续诊断，不静默覆盖单源连接。“替换节点 / 切换模型协议”仍确认配置与公开输出重置。
- 编辑控件与稳定会话限制统一。运行中、暂停、未知请求及会话未读取时不允许编辑，不放宽执行权限。

## P6：结果、历史与名称

- 共享展示严格按 kind/schema 提取 TEXT、模型回答和提示词条目。模型回答使用 `content`；思考摘要独立展开，技术 JSON 过滤签名及供应商协议元数据，原 facts 不改写。
- 历史标题读取该次 run 的精确冻结定义，不以当前图替代。版本缺失持续提示，已有结果仍可读。
- 查看候选只读；完整恢复与新建分叉分别确认、冻结依据并等待本机落盘。失败持续提示、不自动重试；完整恢复保留编辑图和未发布草稿，不重放工具。
- 会话和提示词组可设置本机显示名称；空组不以 UUID 命名。名称与目录状态使用管理端本机表单仓库、CAS 和同目标串行更新，不写入严格资源正文或运行 facts。
- 工作流可归档到本机目录，显示已归档条目后可恢复。定义、会话、未应用草稿和共享资源保留，已打开的图不被关闭；归档不是永久删除。
- 已知会话运行、暂停或不稳定，或原请求待核实时，不能归档；不只检查选中的会话。本批没有永久删除命令。
