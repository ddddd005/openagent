常驻仅是本机显式管理的后台进程，未注册 Windows 服务或开机自启动，不是外部生产部署。停止/更换必须先核实无 active/in-flight 或结果未知业务，启动器只接管自己可验证的进程；具体操作见 [快速启动](QUICKSTART.md)。
