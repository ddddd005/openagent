# 阶段E节点HTTP入口与页面接入执行说明

日期：2026-10-15，Asia/Shanghai。

**状态：用户批准复用现有HTTP服务，为每个节点登记独立通信地址，并允许三个子代理继续施工。主代理依照[41号规划](41-阶段E输入修改与前端节点接入执行规划-2026-10-15.md)及[45号E3回执](45-阶段E节点私有输入与内部通信实施回执-2026-10-15.md)审阅本批实现方案；本说明不是安装或验收结果。**

实际E4代码、限定联合验证和真实隔离页面结果见[47号实施回执](47-阶段E节点HTTP入口与页面限定验收实施回执-2026-10-15.md)。以下保留开工时的职责边界，不替代实施证据。

## 1. 范围与职责

本批为E4，安装当前整体`frontend.node@1`的节点所属HTTP入口、准确绑定、实际页面及工作台打开按钮。节点声明自己的入口，宿主使用现有loopback HTTP服务承载；不分配新数字端口，不构建独立前端服务平台。

沿E3完整原请求和窄channel调用。前端仅向对应后端节点通信，后端调用既有配置、数据与runtime功能；不把私有节点操作加入`GraphApplication.COMMANDS`，不开放通用管理转发或上下文覆盖API。

200ms仍只存在于当前节点私有客户端的输入更新时间中。工作台字段编辑、合规配置模块、其他输入节点、定义层、runtime和检查点不接此定时行为。

## 2. 准确地址与绑定

`W/R/N/S`分别为准确工作流ID、定义修订、节点实例ID及可空会话ID；路径中的`none`表示尚无会话，不代表查找或恢复旧会话。

| 入口 | 用途 |
| --- | --- |
| `/frontend-node/W/R/N/S-or-none/` | 对应节点页面 |
| `/api/graph/frontend-nodes/W/R/N/S-or-none/entry` | 读取节点提供的准确页面及通信地址 |
| `/api/graph/frontend-nodes/W/R/N/S-or-none/channel` | POST E3原包`{owner,operation,parameters}` |
| `/api/graph/frontend-nodes/W/R/N/S-or-none/events` | GET该准确节点绑定的SSE通知 |

入口元数据为`schema_version:1`、`kind:workflow.frontend-node-entry`、准确`owner`及`page_url/channel_url/events_url`。HTTP宿主由已经校验的Host生成实际同源地址，工作台不猜后端端口或复用旧Tavern默认地址。消费端核对完整owner和地址所属准确路径。

路由owner与正文owner必须一致。打开、入口读取、无会话初始化、订阅和回执读取不创建会话、不启动图或构造执行协调器；只有实际start/pause需要执行服务。已有运行的准确节点仍可打开，配置编辑锁不等于禁止只读开窗。

## 3. 节点所属通知

使用只属于当前前端节点的连接集合，不建设通用push总线、历史重放日志或任意topic订阅。

- `snapshot`事件来自后端已经完成真实数据读取的`workflow.frontend-node-snapshot`。实际追加提交后才重读、缓存并通知；回滚不发布，网络写失败不回滚已经提交的数据。
- 每连接只保留最新完整快照，以同一实际对象修订去重。显式state读取不导致“读取→通知→再次读取”的无限循环。
- `state_changed`事件为`{schema_version:1,kind:workflow.frontend-node-state-changed,owner}`。只在真实运行结束、无法确认的结束状态或暂停请求实际接纳后通知对应绑定；暂停安全点由真实运行结束状态确认，不在所有配置/数据事务上广播。
- 页面收到准确通知后，仍通过节点channel正式读取状态；不直接修改客户端内部值，不通过通知派发业务命令。
- SSE断线明确显示并关闭本连接；显式重新连接或刷新不重发业务请求。关闭页面只释放本客户端与连接，不发送停止或暂停。

## 4. 页面与工作台

实际页面使用E3私有客户端，显示后端展示快照、当前输入和保存/运行状态，提供发送、暂停、刷新、未知原请求核实及固定修改确认。渲染只消费后端`TEXT@2`原文，不新增聊天格式或本地业务存储。

首次start成功返回真实会话时，新建准确port/client读取该会话；不再start一次。固定派生、定义修订推进或部分创建结果明确显示准确新owner，并显式接续，不自动启动或改工作台全局选择。

工作台以既有可信`node-fields`扩展接入整体节点。输入绑定选择器仅列当前图准确`tools.editable-input@1`，允许未绑定，通过已有SDK正式保存；role及自有数据项沿现有配置和权限处理。打开按钮核对已保存的W/R/N/S、未核实请求及实际入口元数据，不查全图唯一节点。多个同类型节点各自打开自己的页面。

## 5. 结果与验收边界

有效公开4xx诊断才作为明确拒绝；5xx、网络断线、响应解析失败或不匹配结果保留unknown，由原请求回执核实，绝不自动换key重发。阶段业务失败仍保留实际创建/启动/控制结果，不被网络状态覆盖。

离线验收覆盖临时数据库和port0测试HTTP、两节点/两会话隔离、无会话零运行创建、实际保存后启动、写后读取通知、暂停状态、错归属/Host/Origin拒绝、客户端页面接线，以及工作台测试、类型检查和隔离构建。视觉验证只使用施工树隔离测试服务与数据，不覆盖用户工作流。

本批不替换旧Tavern入口，不删除有效显式frontend节点或用户图；E5按实际消费者另行接续。重roll、候选、额外Tavern退役及聊天检查点准入不在本批。不得操作产品库、启停产品服务、调用真实模型、提交、合并或推送；实际交付另记回执。
