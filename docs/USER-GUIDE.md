# 使用手册

适用于 2026-10-09 晋升后的现行主干。安装、端口和停止方法见 [快速启动](QUICKSTART.md)；本文以代码实际支持的工作台操作为准，不要求真实模型调用才能编辑或保存。

本次 `develop` 的前端用户化 P1/P2 和 P3/P4 已本地提交，P5/P6 已在工作区实现但未提交；均尚未晋升 `main`。以下新入口、本机草稿、修订、私有 Key 及编辑/结果分层说明适用于开发源码，稳定 BAT 仍运行原主干；范围见 [P1/P2](FRONTEND-P1-P2-2026-10-09.md)、[P3/P4](FRONTEND-P3-P4-2026-10-09.md)和 [P5/P6 记录](FRONTEND-P5-P6-2026-10-09.md)。

## 工作区与节点

左侧“工作流”列出本机工作区的图，单击只选中；选中非当前条目后点击右侧“切换”打开，双击或 Enter 入口保留。顶部加号新建空图，另有“创建串行 Agent 示例”和“创建上下文精简串行示例”图标。首次可读且没有本机存档时建立空普通图。

普通编辑、拖动和改名保持同一工作流身份，只修改本机草稿。“保存工作流”发布下一修订，不改变已选会话。左侧会话显示草稿基准、已发布和会话修订；不一致时可明确“采用已保存修订”并确认，或另建会话。运行不会代替用户发布草稿或重绑旧会话。运行中及暂停时不允许编辑或采用修订。

顶部铅笔修改名称，复制图标才产生独立工作流；撤销图标“放弃工作流修改”恢复已发布基准，未发布新图则从本机目录真正移除，不永久删除已发布定义或会话。未应用表单独立保留。

左上角图标可收起或展开左侧栏。收起后保留“工作流／供应商／内容”入口，点击任一入口展开对应面板；收起再展开同一面板不会丢失未保存的表单。浏览器单独记住收起状态，不改变工作流、会话或运行记录。

使用画布工具栏的“添加节点”加号，或在画布空白处右键进入菜单，再选分类和节点家族；菜单可搜索。默认有基础工具、格式转换、变量、提示词、模型、Agent、上下文、酒馆、前端展示 9 类。单一路线直接添加；模型来源、模型调用和 Agent 选择 DeepSeek/Gemini 协议。这里不是历史版本菜单。

选中节点后在右侧“配置”编辑正文与常用字段。“运行设置”中的“作为运行目标”指定执行根，“前序节点”配置控制顺序，虚线只表达先后、不传数据；“允许聊天端读取的结果”控制消费端权限，不会自动全部公开。UUID、版本、原始配置和契约在“技术详情”中。

移动到可拖动端口时显示外环；拖线时端口显示兼容或不兼容。无效连接、单源输入已有连线、重复和循环会被拒绝，不覆盖旧线。已因配置变化失配的连线保留、标红并提示。使用工具栏撤销/重做，选中后可复制或删除。

“替换节点 / 切换模型协议”会明确要求重置配置和公开输出；旧连线保留用于诊断，不自动猜测端口映射。替换后重填字段、检查连接和绑定，必要时撤销。所有型号和协议变化应先在新草稿或独立副本中核对，不能把已有历史静默当成新协议。

选中工作流后可使用右侧归档图标，仅从本机目录隐藏；顶部“显示已归档工作流”可显示并恢复。定义、会话、共享资源和草稿均保留，已打开的图不会因此关闭。本批没有永久删除入口；已知会话运行、暂停、不稳定或原请求待核实时不能归档。

## 模型与思考

### 供应商

点击左侧“供应商”，在“模型供应商 · 当前资源”新增；可使用原环境凭据路线，也可在 P4 开发版直接输入私有 Key：

| 路线 | 供应商协议 | 默认服务地址 | 后端凭据引用 |
| --- | --- | --- | --- |
| DeepSeek | Chat Completions | `https://api.deepseek.com` | `env:DEEPSEEK_API_KEY` |
| Gemini | Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` | `env:GEMINI_API_KEY` |

填名称、协议和地址，保持启用。地址允许 HTTPS 或本机 HTTP，不允许 URL 密码、query 或 fragment。既有资源的协议不可直接修改；需要另一协议时新建资源。

使用本机 Key 时，先点“保存 Key”，确认后再点“保存当前资源”。两项保存分开，供应商仍未保存时不能把 Key 已保存当成绑定成功。密码只在表单内存中，切换或关闭后不能恢复未提交 Key；普通草稿仅保管非秘密请求身份。响应丢失后用“核实原 Key 请求”，不重新发送 Key；没有回执或本机清理失败时继续保留锁定。

本机 Key 存于公开数据库旁独立的 `*.credentials.sqlite`，用 Windows 当前用户 DPAPI 及原路径绑定保护。迁移账号、机器或路径不保证可解密，不支持保护的宿主不改存明文；原环境引用继续可用。运行准备后轮换或删除 Key 会阻止该运行后续派发，不默换新 Key 继续。资源保存成功仍不证明账号、网络或模型可调用。

### 模型来源

选择“模型来源”节点，选择已有供应商，填写模型名称、最大输出、temperature 与容量，然后点击“应用模型配置”，最后保存工作流。供应商协议、模型来源协议，以及下游“模型调用”或“Agent 执行”协议必须一致。

供应商选择按节点协议过滤。旁边刷新列表图标可向后端获取已保存供应商的上游型号；列表不支持时仍可手填。未知 Gemini 显示“尚未适配”，不能因发现型号就授予工具或思考能力。容量缺失继续手填；Gemini 输入上限和输出上限独立，不能相加当作总上下文窗口。

当前最大输出限制为 `1..8192`，temperature 为 `0..2`，且模型必须接受这些参数。容量必须显式填写，不能把代码默认值当成供应商真实容量：

- 上下文窗口：目标模型实际允许的输入/输出总窗口。
- 输出预留：至少覆盖最大输出，且小于上下文窗口。
- 摘要最大输出：正数，不超过输出预留。
- 摘要冷输入上限：正数，用于限制精简请求输入。

普通串行示例默认生成待配置的 DeepSeek 路线；若使用 Gemini，分别通过“替换节点 / 切换模型协议”把模型来源及全部 Agent 切为 Gemini。酒馆创建面板可直接选择 Chat/Gemini，复用当前图唯一有效或明确选中的模型配置；否则明确创建待配置流程，不任意选第一条供应商。预置流保留完整 12 节点、上下文写回和聊天追加；创建不运行模型。

### Gemini 思考

Gemini 模型来源提供“关闭”“Token 预算”“强度”及“请求思考摘要”。下表是本仓已登记能力，不是供应商当前账号可用性的保证；外部型号变更需先更新代码能力表，未知型号会被拒绝。

| 代码已登记模型 | 思考模式 | 可选范围 |
| --- | --- | --- |
| `gemini-2.5-pro` | Token 预算 | `-1` 自动或 `128..32768`；不能关闭 |
| `gemini-2.5-flash` | Token 预算 | `-1` 自动或 `0..24576`；支持关闭 |
| `gemini-2.5-flash-lite` | Token 预算 | `-1` 自动、`0` 关闭或 `512..24576` |
| `gemini-3-flash-preview` | 强度 | 最少、低、中、高；不能关闭 |
| `gemini-3.1-pro-preview` | 强度 | 低、中、高；不能关闭 |

请求摘要后，供应商返回的摘要独立展示；没有摘要不应补造。节点“信息”中可读取 Gemini 的 `thinking-summaries` 历史信息源；“状态与结果”和聊天界面在可用时显示可展开摘要。摘要不是完整内部思维链。

工具与思考可以同时使用。签名和协议元数据由后端按原始 part 顺序、工具调用关联和持久化历史回传，不显示为正文，不需要手工填写。缺少必需签名时查看诊断，不能伪造签名、绕过校验或重新派发工具补齐。DeepSeek 路线目前固定关闭思考；两条路线都非流式。

## 提示词与世界书

图内“提示词条目”“提示词分组”等节点产生材料，经“提示词装配”用于普通模型调用，或经“上下文装配”用于 Agent。默认示例的 A/B 提示词是图内材料，不会因新建全局资源自动替换。

左侧“内容”中，“提示词组 · 全局资源”可新增、编辑、复制提示词组；条目支持正文、Role、启用状态、位置、深度与顺序：

- “每次装配”在每次请求装配，不许可精简。
- “仅一次”依靠上下文消费账本避免重复插入，可明确选择保留原文或允许精简；system 材料保留原文。
- “上下文前/中/后”决定位置，中区使用深度；上移/下移调整成员顺序。

图内“提示词分组”也使用同一条目表单；编辑后点击“应用条目”。成员 ID 和 metadata 保留在条目技术详情，半输入数字作为本机草稿保留但不能应用。全局组的“本机显示名称”独立保存，不写入共享资源正文；其他机器不会自动获得该名称。

保存组后，添加“全局提示词引用”，选择资源并“应用提示词引用”；把输出接到“全局提示词解析”，再接材料端口。现行引用节点只选择 schema 2 生命周期资源，资源身份保留范围、类型和 UUID；缺失或停用不会自动换成别的资源。

资源更新产生新的 current 序号，后续运行准备按身份读取和冻结，不能改变已开始运行的依据。组可复制为新的独立身份；当前管理入口不提供持久资源删除、独立导入或旧数据自动迁移。

“内容”的“Lorebook · 全局资源”可新增世界书及条目，设置名称、正文、常驻/关键词模式、扫描深度、主副关键词规则、大小写、递归、概率和注入位置后显式保存。图中使用“全局世界书引用”与“世界书触发”接入材料；资源保存不会自动为现有图接线，也不会触发模型。酒馆功能范围见 [酒馆专项](tavern/README.md)。

## 示例与运行

### 普通串行与精简

“创建串行 Agent 示例”生成 18 个节点；精简示例增加 A/B 两个“上下文精简策略”节点，其他路线一致。原输入分别进入 A/B，A 的本轮分析作为 B 的附加材料；两者独立维护上下文。B 完成后按序写回上下文，再追加用户与最终回答到展示记录。

精简示例可分别配置策略的启用状态、提前精简阈值、保留完整回合深度与精简提示词。阈值 `0` 使用 90% 水位，提示词空白使用默认；目标 tokens 是保留占位，维持 `null`。精简只处理允许精简的较早历史，并保留工具轮次闭合与协议证据，不应靠降低阈值删除必要签名。模型容量与摘要限额仍须真实配置，无法安全精简时看诊断。

配置模型、容量和提示词后点击“保存工作流”。草稿允许先保存，但缺失模型/容量、无效连接或权限会在准备/运行阶段诊断。创建或保存不是执行。

工具栏“本次输入”优先显示后端声明的 TEXT 填写框；默认示例直接填写 `text`。不完整图仍可编辑，只有当前激活节点的必填声明才标作“本次运行必填”；编译失败会保留诊断。复杂对象、PROMPT 和未声明字段仍在“高级 JSON / 未声明输入”中，不会因填写正文而被删除。高级表示示例为：

```json
{"text": "请分析这个问题并给出简短回答。"}
```

点击“启动”显式提交。新建会话可在左侧“会话”点击加号；运行会使用所选会话和保存的定义依据。默认 Agent 通过已注册工具执行，使用 `final_answer` 返回含 `text` 的答案，不能只以自由文本冒充完成交付。

### 聊天入口

保存普通图后，右侧“打开聊天前端”使用精确工作流及可选会话身份。无身份的后端首页只显示未绑定，不初始化业务会话；有待核实原请求时入口不可用。

酒馆从左侧“内容”的“酒馆聊天”面板创建示例。配置模型并保存后，选中图中的“聊天展示”节点，在节点详情点击“打开酒馆”；入口绑定当前工作流及当前选中会话。没有会话时，明确点击“新建会话并打开”，只创建精确已保存修订的会话，不发布草稿、不重绑旧会话、不运行模型。未保存或修订不匹配时按节点诊断处理。其独立展示不替代 Agent 有效上下文；入口仍需要 `workflow.tavern@1.2.0`、单个 TEXT 用户输入及唯一显式公开的酒馆展示输出。

其他会话的待核实请求不会把入口切换到旧会话。页面会保留原请求并提示冲突，明确处理后再继续，不自动重发。裸 `/tavern/` 地址仍不能猜测或新建业务会话。

通用或酒馆聊天都只是图的消费者，不会绕开运行约束。修改图后应核对新定义/副本与当前会话，不把浏览器历史直接当成 Agent 的持久上下文。

## 结果、暂停与恢复

运行期间可刷新观察。点节点查看“状态与结果”，优先展示正文、回答、可展开思考摘要、状态及诊断；模型请求/尝试数仍可读，未知结构保留技术数据回退。签名和供应商协议元数据不作为正文或技术 JSON 展示，后端原记录保留。不选节点时看整图公开输出。“前端展示”可配置展示接线；只有显式公开的端口/信息源交付消费者。

“运行历史”默认查看选中或最后一次运行，标题来自该次运行的精确冻结定义；缺失版本会明确提示，不用当前图替代。点击“查看候选”没有状态变更；恢复完整状态和新建分叉会话分别确认，取消不提交。左侧会话默认用可读名称，展开“会话名称与技术详情”可独立保存本机名称或查看 UUID。

| 状态或动作 | 正确操作 |
| --- | --- |
| 进行中 | 主按钮变“暂停”；等待暂停状态后再“继续” |
| 预算耗尽 | “运行操作”按服务提供的动作增加请求/尝试预算，再继续；增额不是模型 token 配额 |
| 成功结果未接纳 | 用“结果接纳重试”，复用已取得结果，不重新调用模型或工具 |
| 归档失败 | 用“归档重试”，不把它当成重新执行 |
| 确定失败节点 | 现行原生 Agent 不开放失败重试策略；查看诊断及可用动作，不套用旧“只重试 B”流程 |
| 原请求结果未知 | “核实原请求”或资源面板对应核实按钮，保留原 body/key |
| 运行不能继续 | 查看诊断及可用动作，必要时明确“关闭本次运行”，不要反复点启动 |

暂停不会撤销已派发的模型请求/工具，也不保证立即中断；已经发起的调用仍可能收费。表中通用控制项只在服务实际提供对应动作时可用；通用菜单或旧测试出现过的操作不等于当前原生 Agent 具备该能力。所有恢复以服务给出的可用动作和冻结依据为准，不能通过刷新、复制、换 key 或重放工具规避结果未知保护。

完成回合可选择候选完整状态或新建分叉会话；完整恢复只改变会话状态，历史定义单独保管，不覆盖编辑图、发布基准或未发布草稿。跨工作流历史会话不能被当前编辑图直接启动或重绑。酒馆的消息分叉按钮只对应已完成回合检查点，不是任意消息编辑或内核上下文编辑。重新打开可读取已持久化完成历史，但重启后端不承诺恢复原进程内活动 Agent 内核。

## 保存与故障

后端 SQLite 除资源、定义、会话与事实外，另保存本机工作台草稿、未提交资源表单、节点字段、无效 JSON、半输入数字、运行输入及聊天输入；原请求先确认落盘再提交业务。浏览器只保留收起等轻量偏好和未删除的旧记录，不再是这些新草稿的保存权威。正式/开发默认数据库不同，不自动合并。

本机草稿落盘不等于“保存工作流”或“保存当前资源”：前者保管未完成编辑，后两者才发布或提交。不同节点、会话和资源按归属恢复；资源面板可选择“未提交草稿”继续编辑。配置依据变化会保留旧文并提示，需明确载入或放弃，不静默应用到新配置。

关闭浏览器前，确认没有“尚未写入本机”或保存错误。应用内切换会等待落盘，失败时保留当前页面；关闭提示不保证能完成异步保存。尚在内存的内容不能承诺关闭后恢复。API Key 不进入通用草稿；P4 的私有保存与原环境路线见上文。

旧稳定版的“保存记录无法读取或版本不兼容，原始记录未覆盖”表示浏览器记录未通过安全读取，并非供应商接口报错。本次版本读取旧记录时：

1. 点击“导出原记录”，保留捕获的原文，不先清空 localStorage。
2. 可验证的现行浏览器记录提供“导入浏览器记录”。导入需明确点击，原文不覆盖，待核实请求只保管和读取原回执，不自动执行。
3. 损坏或未知格式不导入；已有本机记录的身份冲突也不覆盖。不再提供另一个浏览器保存工作区作为本机落盘替代。旧资源和聊天请求同样需要各自入口显式导入。

“暂无供应商当前资源”是所连接后端库确实无资源的状态；读取失败会单独显示错误。确认 BAT 的数据库与端口后明确创建资源，不自动合并其他库或迁移凭据。

现行版本按明确退役名单删除旧测试图和关联记录，不保留旧节点菜单或静默迁移。未知格式、未知扩展和真正损坏记录与明确退役不同，不能因“打不开”猜测删除。详细边界见 [存档恢复](tavern/LOCAL-STORAGE-RECOVERY.md) 和 [节点目录](NODE-DIRECTORY-2026-10-09.md)。

## 费用与停止

安装依赖可能联网，浏览、编辑、保存和只读核实不派发模型。显式运行 Agent/模型节点、上下文精简请求或重试确定失败节点可能联网收费；串行示例至少涉及 A/B 两个 Agent，请求次数还受工具轮次与精简影响。最大输出、思考预算和运行预算都不是总费用保证。

验收时使用短输入、合理参数和独立库，按需要配置真实凭据。不要上传密钥、完整请求头、数据库或浏览器导出原文中的私有内容。停止前确认没有活动或待核实业务，按 [快速启动](QUICKSTART.md#停止与故障) 使用本次服务的停止方式；停止不删除数据，不取消已经发生的费用。
