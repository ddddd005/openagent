# 使用手册

适用于2026-10-15唯一施工树，不能据此认定稳定main已经部署本批。安装、分支、端口和停止方式见[快速启动](QUICKSTART.md)。普通配置编辑与保存不需要真实模型调用；聊天安装见[55号](中期检查2/55-聊天候选数据层与重roll检查点接续实施回执-2026-10-15.md)，实际退役及限定离线收口见[57号](中期检查2/57-D-E阶段旧内容退役与收口实施回执-2026-10-15.md)。新菜单已默认前端节点`@2`，现有服务尚未更新，完整人工搭流和真实模型验收待进行。

## 工作区与节点

左侧“工作流”列出当前后端的图，单击选中，通过切换、双击或Enter打开。新建只建立空普通工作流，不创建会话、不运行模型。旧酒馆、串行Agent及精简预设入口已经退出。

节点编辑通过正式配置入口提交后端，不维护独立持久编辑草稿。无有效会话时原地保存；有有效会话时，固定配置修改、节点增加/复制/删除须确认后派生无会话新工作流，不继承原运行数据。可调字段原地保存，对下一次准备生效。运行中不手动修改会话数据，不提供“采用修订”重绑原会话。

名称、画布布局与正式配置各走对应管理入口。表单内存编辑不等于已保存；冲突或保存失败明确提示，不将内存内容报告为已落盘。

左上角图标可收起或展开左侧栏。收起后保留“工作流／供应商／内容”入口，点击任一入口展开对应面板；收起再展开同一面板不会丢失未保存的表单。浏览器单独记住收起状态，不改变工作流、会话或运行记录。

使用画布添加按钮或空白处右键菜单选择分类及节点家族，菜单可搜索。世界书与前端节点各有分类；菜单只提供准确的当前声明，不是历史版本选择器。模型协议由全局模型配置决定。

选中节点后编辑正文、常用字段、准确对象引用及授权。控制边表达先后依赖，不传数据；普通执行按工作分类和实际连通关系筛选，不再通过旧“作为运行目标”复选框筛选。UUID、版本及原始契约放在技术详情，公开输出和对象ACL不会因显示折叠而改变。

移动到可拖动端口时显示外环；拖线时端口显示兼容或不兼容。无效连接、单源输入已有连线、重复和循环会被拒绝，不覆盖旧线。已因配置变化失配的连线保留、标红并提示。使用工具栏撤销/重做，选中后可复制或删除。

“替换节点 / 切换模型协议”会明确要求重置配置和公开输出；旧连线保留用于诊断，不自动猜测端口映射。替换后重填字段、检查连接和绑定，必要时撤销。所有型号和协议变化应先在新草稿或独立副本中核对，不能把已有历史静默当成新协议。

开发版工作流和会话可按目标归档或删除。归档先停止所属运行、保存只读历史，已归档记录可查看但不恢复或续跑；删除清理所属数据，不删除全局资源或私有 Key。归档写入失败不报完成；未核实执行证据阻止删除。正式 `main` 的旧目录隐藏式归档未由本批更改。

## 模型与思考

### 供应商

点击左侧“供应商”，在“模型供应商”新增；供应商与全局命名模型配置在同一个入口管理。唯一凭证入口是本页 API Key 密码框；环境变量密钥和“后端凭据引用”选择器已退出开发版。

| 路线 | 供应商协议 | 默认服务地址 |
| --- | --- | --- |
| DeepSeek | Chat Completions | `https://api.deepseek.com` |
| Gemini | Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` |

填名称、协议和地址，保持启用。地址允许 HTTPS 或本机 HTTP，不允许 URL 密码、query 或 fragment。既有资源的协议不可直接修改；需要另一协议时新建资源。

新增供应商先进入草稿，填写或修改名称、协议、地址、启用状态和 API Key 后，点击唯一的“保存供应商”按钮提交整份配置。输入 Key 不会禁用上方字段，也不会因同一草稿的字段变化丢失 Key。已有供应商同时修改 URL 和 Key 时一起保存；Key 留空保持已保存 Key，不删除或重复写入密钥。未点击保存前不改变生效供应商或私有 Key。

Key 只在表单内存中，刷新、切换或关闭后不能恢复未提交 Key；本机草稿保管非秘密表单和原请求身份。提交中或结果未知时锁定修改。响应丢失后用“核实原 Key 请求”，只核实原配置与 Key，不重新发送。失败后单独“完成原供应商保存”的补绑定入口已移除；Key 已保存不等于整份配置已完成，部分失败明确报告。权威回执及当前整份配置均核实才报告成功。原请求无法核实，可确认“归档并解除锁定”，先归档并重读核实，不撤销已经发生的保存、不自动重发。归档失败保留原请求。表单版本冲突时，右上刷新图标可先归档旧表单，再重新读取生效配置。

本机 Key 存于公开数据库旁独立的 `*.credentials.sqlite`，用 Windows 当前用户 DPAPI 及原路径绑定保护。迁移账号、机器或路径不保证可解密，不支持保护的宿主明确拒绝，不回退明文或环境变量。运行准备后轮换或删除 Key 会阻止该运行后续派发，不默换新 Key 继续。资源保存成功仍不证明账号、网络或模型可调用。

本轮真实验收使用 DeepSeek，由用户启动开发页面并输入、保存自己的 Key。全部职责订正完成后统一验收合并到 `main`；当前未进行在线模型验收。

### 模型配置

在同一“供应商”入口的“模型配置”中新增命名配置，选择已保存供应商，填写型号、最大输出、温度、思考设置及容量，然后“保存模型配置”。同一型号可以保存多套命名配置供多个工作流共享。

获取型号列表只在模型配置入口进行，使用已保存供应商、协议和序号；列表不支持时仍可手填。未知 Gemini 显示“尚未适配”，不能因发现型号就授予工具或思考能力。发现列表不自动填写任何容量，即使上游提供上限也只作发现结果，容量始终手填。

工作流“模型来源”只选择全局命名配置，不保存Key或模型覆盖值，也不从节点获取上游列表。每个新请求准备时读取当前已保存配置，包括活动运行的后续新请求；已经准备或发出的请求不追改。

模型四参数是思考强度、上下文长度、压缩阈值和输出上限；长度/阈值/上限既定默认值为`300000 / 0.85 / 32000`，不代表供应商实际容量。容量仍须手填，协议能力校验保留。旧工作流二次限额、8192人为上限及摘要额外1024上限已退出，普通与摘要使用各自当次准备设置中的输出上限。

### Gemini 思考

供应商入口的 Gemini 模型配置提供“关闭”“Token 预算”“强度”及“请求思考摘要”。下表是本仓已登记能力，不是供应商当前账号可用性的保证；外部型号变更需先更新代码能力表，未知型号会被拒绝。

| 代码已登记模型 | 思考模式 | 可选范围 |
| --- | --- | --- |
| `gemini-2.5-pro` | Token 预算 | `-1` 自动或 `128..32768`；不能关闭 |
| `gemini-2.5-flash` | Token 预算 | `-1` 自动或 `0..24576`；支持关闭 |
| `gemini-2.5-flash-lite` | Token 预算 | `-1` 自动、`0` 关闭或 `512..24576` |
| `gemini-3-flash-preview` | 强度 | 最少、低、中、高；不能关闭 |
| `gemini-3.1-pro-preview` | 强度 | 低、中、高；不能关闭 |

请求摘要后，供应商返回的摘要独立展示；没有摘要不应补造。节点“信息”中可读取 Gemini 的 `thinking-summaries` 历史信息源；“状态与结果”和聊天界面在可用时显示可展开摘要。摘要不是完整内部思维链。

工具与思考可以同时使用。签名和协议元数据由后端按原始 part 顺序、工具调用关联和持久化历史回传，不显示为正文，不需要手工填写。缺少必需签名时查看诊断，不能伪造签名、绕过校验或重新派发工具补齐。DeepSeek 路线目前固定关闭思考；两条路线都非流式。

## 提示词与世界书

图内“提示词条目”“提示词分组”等节点产生材料，经“提示词装配”用于普通模型调用，或经“上下文装配”用于 Agent。默认示例的 A/B 提示词是图内材料，不会因新建全局资源自动替换。

左侧“内容”中，“提示词组 · 全局资源”可新增、编辑、复制提示词组；条目支持正文、Role、启用状态、位置、深度与顺序：

- “每次装配”在每次请求装配，不许可精简。
- 装配按材料是否已经在其中判重，不建立上下文once账本或新来源证明格式；精简后也按同一原则处理。
- “上下文前/中/后”决定位置，中区使用深度；上移/下移调整成员顺序。

图内“提示词分组”也使用同一条目表单；编辑后点击“应用条目”。成员 ID 和 metadata 保留在条目技术详情，半输入数字作为本机草稿保留但不能应用。全局组的“本机显示名称”独立保存，不写入共享资源正文；其他机器不会自动获得该名称。

保存组后，添加“全局提示词引用”，选择资源并“应用提示词引用”；把输出接到“全局提示词解析”，再接材料端口。现行引用节点只选择 schema 2 生命周期资源，资源身份保留范围、类型和 UUID；缺失或停用不会自动换成别的资源。

资源更新产生新的current序号，后续读取采用已保存新内容，不刷新此前已加载值或改写已发送请求。组可复制为独立身份，不提供旧数据自动迁移。

“内容”的“Lorebook · 全局资源”可新增世界书及条目，设置名称、正文、常驻/关键词模式、扫描深度、主副关键词规则、大小写、递归、概率和注入位置后显式保存。图中使用“全局世界书引用”与“世界书触发”接入材料；资源保存不会自动为现有图接线，也不会触发模型。酒馆功能范围见 [酒馆专项](tavern/README.md)。

## 搭图与运行

根据实际需要手动连接输入、材料、模型/Agent、上下文读取/更新、变量、Lorebook和前端节点。Agent和前端提供节点分别登记具体独立项；同类型可有多项，消费者须选准确键并取得授权，不能按类型取第一项。

读取节点输出加载时的一份值。数据层后续变化不会刷新该输出；流内处理也不会自动写回，须明确调用更新节点，需要新值再读取。变量注册按钮属于非工作交互，不自动进入普通执行计划。

配置可以先保存，缺少模型/容量、无效连接或权限在对应准备/运行阶段诊断。创建或保存不是执行；输出后若仍有写回或其他工作节点，runtime仍等待其实际完成。

工具栏“本次输入”优先显示后端声明的 TEXT 填写框；默认示例直接填写 `text`。不完整图仍可编辑，只有当前激活节点的必填声明才标作“本次运行必填”；编译失败会保留诊断。复杂对象、PROMPT 和未声明字段仍在“高级 JSON / 未声明输入”中，不会因填写正文而被删除。高级表示示例为：

```json
{"text": "请分析这个问题并给出简短回答。"}
```

点击“启动”显式提交。新建会话可在左侧“会话”点击加号；运行会使用所选会话和保存的定义依据。默认 Agent 通过已注册工具执行，使用 `final_answer` 返回含 `text` 的答案，不能只以自由文本冒充完成交付。

### 节点前端入口

添加`frontend.node@2`，选择对应可编辑输入节点，保存后从该节点打开页面。入口绑定准确工作流、修订、节点及可空会话；打开不创建会话或运行。首次发送先把输入交对应后端节点，再由该节点调用合规输入修改及独立启动功能。

节点接收本轮新增消息，写入自己的逻辑聊天项，再由后端读取正式值作为展示快照。前端不能回传上下文覆盖；前端未打开时节点仍可执行。私有200ms输入更新时间只属于该节点，未接纳的页面内存输入不保证恢复。

页面支持继续、结束本轮、检查点读取/分叉、重roll及候选选择。重roll保持本楼轮前数据和首次接纳输入；每个成功候选关联实际成功点，全部候选保留。有下文的楼层不能在原分支换选或重roll；楼层分叉保留全部候选，目标独立、源不变、不自动运行。

原请求结果未知时只核实原body/key，不重新派发或自动切回旧对象。旧`/`、`/static/index.html`、`/tavern/`及`/tavern/index.html`返回410，不猜节点或创建业务。

## 结果、暂停与恢复

运行期间可刷新观察。点节点查看“状态与结果”，优先展示正文、回答、可展开思考摘要、状态及诊断；模型请求/尝试数仍可读，未知结构保留技术数据回退。签名和供应商协议元数据不作为正文或技术 JSON 展示，后端原记录保留。不选节点时看整图公开输出。“前端展示”可配置展示接线；只有显式公开的端口/信息源交付消费者。

“运行历史”只查看真实运行，标题来自准确冻结定义，缺失时不使用当前编辑图替代。它不承担聊天候选选择或同会话历史恢复。会话名称可独立保存，不修改运行事实。

| 状态或动作 | 正确操作 |
| --- | --- |
| 进行中 | 主按钮变“暂停”；等待暂停状态后再“继续” |
| 成功结果未接纳 | 用“结果接纳重试”，复用已取得结果，不重新调用模型或工具 |
| 归档失败 | 用“归档重试”，不把它当成重新执行 |
| 确定失败节点 | 现行原生 Agent 不开放失败重试策略；查看诊断及可用动作，不套用旧“只重试 B”流程 |
| 原请求结果未知 | “核实原请求”或资源面板对应核实按钮，保留原 body/key |
| 运行不能继续 | 查看诊断及可用动作，必要时明确“关闭本次运行”，不要反复点启动 |

暂停不会撤销已派发的模型请求/工具，也不保证立即中断；已经发起的调用仍可能收费。表中通用控制项只在服务实际提供对应动作时可用；通用菜单或旧测试出现过的操作不等于当前原生 Agent 具备该能力。所有恢复以服务给出的可用动作和冻结依据为准，不能通过刷新、复制、换 key 或重放工具规避结果未知保护。

普通检查点分叉只在新会话装载所选白名单状态，复制该点及父级前缀，不覆盖源。当前未锁楼的候选选择/重roll是已批准的有限计算值接续，不开放通用历史回写。重新打开可读取已持久化数据；重启不保证恢复原进程活动内核。

## 保存与故障

后端维护正式配置、资源、会话当前值、运行事实及完整原请求。普通表单仅有内存编辑，不能承诺刷新或关闭后恢复；输入只有收到后端接纳才能称为已保存。配置冲突、失败及unknown分别报告。Key不进入通用表单证据，正式/开发库不自动合并。

旧稳定版的“保存记录无法读取或版本不兼容，原始记录未覆盖”表示浏览器记录未通过安全读取，并非供应商接口报错。开发版不再使用该兼容恢复流程：

1. 旧工作台读取、导入、自动归档、“旧版存档”和另建兼容工作区入口已经移除，只读取当前后端工作台。
2. 旧资源原请求仅核实原回执，不恢复表单、不写入 intent、不重放。原浏览器证据键仍保留，本轮未实际清理浏览器存储。
3. 旧聊天/酒馆直接consumer入口也已经退出；存量原请求只读核实，不导入新节点或重新执行。实际浏览器清理须另行授权，先分离未知请求证据。

“暂无供应商当前资源”是所连接后端库确实无资源的状态；读取失败会单独显示错误。确认 BAT 的数据库与端口后明确创建资源，不自动合并其他库或迁移凭据。

开发版正常启动不再扫描或删除旧产品数据，显式清理只作用于已授权且核实路径的开发范围；不因为“打不开”清除稳定库、私有 Key 或未知请求证据。旧存档修补仅为[历史参考](tavern/LOCAL-STORAGE-RECOVERY.md)，当前清理结果见首批实施记录。

## 费用与停止

安装依赖可能联网，浏览、编辑、保存和只读核实不派发模型。显式运行 Agent/模型节点、上下文精简请求或重试确定失败节点可能联网收费；串行示例至少涉及 A/B 两个 Agent，请求次数还受工具轮次与精简影响。最大输出、思考预算和运行预算都不是总费用保证。

验收时使用短输入、合理参数和独立库，按需要配置真实凭据。不要上传密钥、完整请求头、数据库或浏览器导出原文中的私有内容。停止前确认没有活动或待核实业务，按 [快速启动](QUICKSTART.md#停止与故障) 使用本次服务的停止方式；停止不删除数据，不取消已经发生的费用。
