# 现行节点目录与二级菜单

日期：2026-10-09。实现和验收在 `develop` 完成，随后按用户授权收录为新 `main` 主干；旧正式源码已归档供参考，见 [主干晋升记录](MAIN-PROMOTION-2026-10-09.md)。两个 BAT 的脚本内容未改；正式入口通过更新后的 `main` 工作区使用本版。

## 范围

按用户确认，同类型节点只保留当前可用路线。旧实现、旧路线测试与旧测试图删除，不保留历史版本菜单、迁移或高级兼容配置。DeepSeek 与 Gemini 是当前模型协议，不是可互相覆盖的历史版本。

默认目录为 44 个可执行声明、41 个家族、9 个一级分类：基础工具、格式转换、变量、提示词、模型、Agent、上下文、酒馆、前端展示。二级菜单只列节点家族，世界书与聊天归入酒馆，展示记录仍为独立家族。

两个串行示例统一为当前原生上下文图，区别只在是否接入精简策略。工具协议、思考摘要、供应商元数据、Gemini 签名及其原始 part 顺序继续保留，摘要与签名不混入回答正文。

已移除增量/绑定/摘要上下文路线、旧 Agent delta、旧摘要压缩包和无容量模型来源。对应专用测试删除，通用业务、权限、工具结果、暂停、结果接纳、回执、持久化和多轮测试改用现行图。

## 菜单与编辑

- 单一现行声明直接添加；模型来源、模型调用、Agent 只选择 DeepSeek/Gemini 协议。
- 未知扩展归入“其他”，只提供最新安装声明，不提供历史版本选择器。
- 配置弹窗展示实际输入/输出契约，不推测端口兼容性。
- 切换协议须明确确认重置配置和公开输出；沿用节点替换操作与撤销，不猜测端口映射。
- 提交前核对工作流、视图、会话、文档、目录、包锁及编辑锁；模态焦点保护、Escape 取消和焦点恢复保留。
- 菜单支持悬停、点击、键盘和边缘定位；窄屏在同一面板进入分类。

## 旧图清理

SQLite 存储升级至 v15，复用已有单事务退役流程，按明确的旧节点 ID/版本或退役包锁识别旧图，整组删除其定义、会话、运行、产物、对象、事实、manifest 和关联回执。引用旧历史或共享旧对象 revision 的关联测试内容也一起删除。当前包选择仅移除明确退役的兼容/旧压缩包。

旧 `workflow.prompt-resource@1` 当前值及其关联图和资源回执也删除，避免它们阻塞现行资源列表。生命周期提示词资源 `@2`、DeepSeek/Gemini 供应商资源和无关内容保持不变。

浏览器工作台存档的草稿、已保存定义与待确认请求正文也使用相同的精确身份判定；包含旧路线的条目整图清除，保留无关联现行图，重新选择现行条目。不是把旧节点静默升级为新节点，不会自动重发请求或执行工具。

未知插件、未知版本、普通正文中出现的旧节点名称不作为删除依据；不以“当前目录缺失”猜测退役。无关联现行记录保持原始内容。本轮只在隔离临时库和独立浏览器 context 中验证，未打开稳定默认库，也未操作用户浏览器存档。
