# 酒馆插件包专项

登记日期：2026-10-08；现行说明订正于 2026-10-09，Asia/Shanghai。本目录管理 `workflow.tavern` 的勘察、实施与验收，历史记录与当前使用说明分开。

## 现行入口

当前代码已随 2026-10-09 测试版晋升进入 `main` 并正常推送。使用仓库根目录 `start.bat` 启动主干，`start-dev.bat` 启动 `develop` 的隔离验收环境；不使用原开发机固定安装的旧快照。安装与端口见 [快速启动](../QUICKSTART.md)，详细操作见 [使用手册](../USER-GUIDE.md)。

工作台左侧“内容”提供“酒馆聊天”面板：创建酒馆示例，配置模型与容量并保存，再“打开酒馆”。创建草稿不运行模型。独立酒馆壳在对应后端 `/tavern/`，但没有身份的首页不是业务会话入口。

当前默认精确包为 `workflow.tavern@1.2.0`，保留全局世界书资源/触发、提示词组管理、酒馆聊天读取/追加/展示，以及已完成回合检查点分叉。酒馆入口需要单个 TEXT 用户输入和唯一显式公开的 `TAVERN_CHAT_DISPLAY@1`。使用 Gemini 时同步切换模型来源与 Agent 协议，工具及思考签名走共用 Runtime，不另建无工具执行路径。

世界书与聊天节点统一在“酒馆”分类，当前中文家族名为“世界书条目”“世界书分组”“全局世界书引用”“世界书触发”“读取聊天记录”“追加聊天记录”“聊天展示”；不再按历史版本展开菜单。全局提示词组继续复用通用提示词资源，不建立另一套预设引擎。

酒馆聊天展示与 Agent 原生有效上下文是不同对象，不能通过修改展示记录伪造内核上下文。首版仅从已完成回合分叉，不提供任意楼层编辑、活动内核跨进程恢复或完整 ST 功能。
