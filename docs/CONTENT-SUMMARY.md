# 汇总、输入装配与世界书

日期：2026-11-04。本文记录本次使用体验调整，不替代旧运行事实，也不迁移已保存工作流。

## 已确定的职责

汇总归集提示词材料、上下文和本轮输入，供读取或处理结构内容的消费者使用。汇总不执行生命周期注入或最终消息排布。输入装配面向 Agent，在最终调用前生成带消息、布局及来源的冻结输入。

世界书只读外部内容，并且只输出自身命中的结构化提示词。它不修改、不转发输入，不管理原输入的继续传递。

## 新节点与数据

| 声明 | 输入 | 输出 |
| --- | --- | --- |
| `prompts.summary@3` 提示词/上下文汇总 | 可选 `summary`、`view`、`current_input`、多路 `input` 提示词材料 | `CONTENT_SUMMARY@1` |
| `context.assembly@7` 输入装配 | 可选 `summary`、`view`、`current_input`、多路 `materials`、单一 `tool_prompt` | Agent 使用的 `PROMPT@6` |
| `lorebook.item/group/global-activate@2` | 多路 `structured` 与多路 `text`；全局触发另需 `resource` | 自身命中的 `PROMPT_MATERIALS@1` |
| `tools.prompt-to-text@2` | `PROMPT_MATERIALS@1` 或原有 `PROMPT@2` | `TEXT@2` |

汇总固定保留 `materials` 和来源绑定；有上下文时成对保留 `context/context_ref`，有本轮输入时成对保留 `current_input/current_input_ref`。缺少的部分不伪造。重新汇总可以添加材料，但不能把不同上下文或不同本轮输入静默合并。最终输入装配必须取得上下文和本轮输入，缺失时直接报告 `input_assembly_incomplete`。

结构口明确接受 `CONTENT_SUMMARY@1`、`CONTEXT_VIEW@5`、`PROMPT_MATERIALS@1` 和未装配的 `PROMPT@2`。拒绝 `PROMPT@6`，也拒绝已装配的 `PROMPT@2`。文本口只接受 `TEXT@2`；其他内容需要显式转换。

## 世界书匹配规则

- 结构化上下文的历史 user/assistant 文本及本轮输入，沿用已有逻辑楼层和 `scan_depth`。
- 普通提示词从结构口输入时按正文整体匹配，不受历史楼层深度裁剪；元数据不作为正文。要进入文本口时，必须先使用提示词转文本，不隐式跨类型接线。
- 文本口整体参与规则匹配，不受历史楼层深度裁剪，适合上游模型输出自定义触发词。
- 上游世界书材料仅按原有递归规则参与；合并及提示词投影保留其来源识别。
- 概率、禁用、变量读取及有界递归规则保留。两口合计受输入数量和字节预算限制。

## 典型接线

```text
上下文 / 本轮输入 / 提示词 -> 汇总 -> 世界书结构口
                              |       |
                              |       +-> 新汇总 input 或输入装配 materials
                              +----------> 新汇总 summary 或输入装配 summary

上游模型最终文本 -----------------------> 世界书文本口
普通提示词 -> 提示词转文本 -------------> 世界书文本口

输入装配 -> Agent -> 结果 / 上下文写回
```

同一数据口可声明准确的多类型白名单；编译器、执行器与前端连线检查均按已登记的类型及版本验证，不引入隐式转换或任意 JSON 输入。

## 保留的边界

新节点作为新声明版本注册。旧汇总、普通提示词装配、上下文装配及世界书版本仍可读取和运行。普通提示词装配退出新增菜单，其已有普通模型调用图不自动改写。当前新增入口选择新版汇总、输入装配及世界书。

所有运行输入仍来自已接纳产物。通过汇总取得的上下文会核验准确引用、会话归属及原生上下文来源；最终 Agent 输入和上下文写回继续使用原有冻结凭据。未改变调度器、模型请求、会话数据权限或历史证据。

多类型白名单目前用于带有生产者端口类型的工作流连线。`graph_tool_host.py` 的工具适配器直传输入仍只校验目标端口主类型：自定义 `PureToolBindingAdapter` 若向 `tools.prompt-to-text@2` 直接传入备选类型 `PROMPT@2`，会被拒绝。当前没有已注册适配器使用这条组合；原有转换节点和普通图连线不受影响。工具直传的类型身份契约不在本次调整范围内。
