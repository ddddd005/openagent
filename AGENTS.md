# Workflow Lifecycle

- Develop changes on `develop`; the normal `start.bat` must keep selecting a clean `main` checkout.
- When a change retires a workflow format, node route or test template, include archival or explicit cleanup of the obsolete test workflows in the same delivery. Do not leave obsolete records producing a permanent startup warning.
- Archive unknown or damaged browser workbench records byte-for-byte to the local backend before clearing their old browser namespace. If archival or acknowledgement fails, retain the original and show the real failure.
- Do not replay pending model or tool requests, silently upgrade node versions, or clear current usable workflows merely because the UI changed.
- Verify save/reload, archive failure, original-request reconciliation and current workflow preservation. Do not automatically push or start hidden services.
